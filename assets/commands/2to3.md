# TAGLINE

automated Python 2 to Python 3 code converter

# TLDR

**Show changes without applying**

```2to3 [script.py]```

**Convert file in place**

```2to3 -w [script.py]```

**Convert entire directory**

```2to3 -w [directory/]```

**Apply specific fixers only**

```2to3 -f [print] -f [import] [script.py]```

**List available fixers**

```2to3 -l```

**Convert in place without creating .bak files**

```2to3 -w -n [script.py]```

**Write converted files to a different directory**

```2to3 -w -n -o [out_dir/] [script.py]```

# SYNOPSIS

**2to3** [_options_] _file_|_directory_

# PARAMETERS

**-w**, **--write**
> Write changes to files

**-n**, **--nobackups**
> Don't create .bak backup files

**-f** _fixer_, **--fix** _fixer_
> Apply specific fixer

**-x** _fixer_, **--nofix** _fixer_
> Exclude specific fixer

**-l**, **--list-fixes**
> List available fixers

**-e**, **--exec-function**
> Treat **exec** as a function (skip the exec fixer).

**-p**, **--print-function**
> Treat **print** as a function (skip the print fixer). Useful when the file already uses **from __future__ import print_function**.

**-d**, **--doctests_only**
> Only fix doctests inside the file.

**-W**, **--write-unchanged-files**
> Write output even for unchanged files (useful with **-o**).

**--add-suffix** _SUFFIX_
> Append this suffix to output filenames instead of overwriting.

**-j** _n_, **--processes** _n_
> Run in parallel with n processes

**-o** _dir_, **--output-dir** _dir_
> Write converted files to directory

**-v**, **--verbose**
> More verbose output

**--no-diffs**
> Don't show diffs of the refactoring.

# DESCRIPTION

**2to3** is an automated Python 2 to Python 3 code translator. It parses Python 2 source code and applies "fixers" that transform incompatible syntax and library calls to their Python 3 equivalents.

Common transformations include:
- **print** statement to **print()** function
- **unicode** to **str**, **long** to **int**
- **raw_input()** to **input()**
- Iterator methods (.iteritems() to .items())
- **except Exception, e** to **except Exception as e**
- Library renames (urllib, ConfigParser, etc.)

It is normally invoked as **2to3** or **python -m lib2to3**. It handles most mechanical changes but may require manual review for semantic differences between Python 2 and 3.

# CAVEATS

2to3 makes syntactic changes but cannot handle all differences. Code behavior may still differ, especially around:
- String/bytes handling
- Integer division
- Dictionary ordering (pre-Python 3.7)
- Unicode text processing

Running **-w** without **-n** creates .bak files that may clutter version control.

**2to3** and **lib2to3** were deprecated in Python 3.11 and **removed in Python 3.13**; run it with Python 3.12 or older. Its grammar cannot parse newer Python 3 syntax (e.g. match statements). Python 2 reached end-of-life in January 2020; alternatives such as **futurize** and **python-modernize** are also largely unmaintained.

# HISTORY

**2to3** was written by Collin Winter and others and shipped with **Python 2.6 and 3.0** in **2008** as part of **lib2to3**. It was deprecated in Python 3.11 (lib2to3 could not parse newer grammar) and removed from the standard library in **Python 3.13** (2024).
