# TAGLINE

Code coverage report uploader for the Codecov service

# TLDR

**Upload coverage report with token**

```codecovcli upload-process -t [token]```

**Upload only a specific coverage file**

```codecovcli do-upload -t [token] -f [coverage.xml] --disable-search```

**Upload with coverage flags**

```codecovcli do-upload -t [token] -F [unittests]```

**Upload for a specific commit SHA**

```codecovcli do-upload -t [token] -C [commit_sha]```

**Upload with verbose output**

```codecovcli -v upload-process -t [token]```

**Create commit and upload in one step**

```codecovcli upload-process -t [token] -r [owner/repo] --git-service [github]```

**Dry run** without uploading

```codecovcli do-upload -t [token] --dry-run```

# SYNOPSIS

**codecovcli** [_global-options_] _command_ [_options_]

# PARAMETERS

**-t**, **--token** _TOKEN_
> Repository or global upload token. Can also be set via CODECOV_TOKEN environment variable.

**-f**, **--file** _FILE_
> Specific coverage report file to upload.

**-F**, **--flag** _NAME_
> Flag to group coverage (e.g., unittests, integration). May be specified multiple times.

**-C**, **--sha**, **--commit-sha** _SHA_
> Commit SHA (40 characters) to associate with the upload.

**-B**, **--branch** _NAME_
> Branch name for the upload.

**-r**, **--slug** _OWNER/REPO_
> Repository slug (owner/repo).

**-n**, **--name** _NAME_
> Custom upload name.

**--git-service** _SERVICE_
> Git hosting service (github, gitlab, bitbucket, github_enterprise, gitlab_enterprise, bitbucket_server).

**-v**, **--verbose**
> Enable verbose logging (global option, placed before the command).

**-P**, **--pr**, **--pull-request-number** _N_
> Pull request number, overriding CI environment variables.

**-b**, **--build**, **--build-code** _CODE_
> Build number.

**-e**, **--env**, **--env-var** _VAR_
> Environment variables to include with this build.

**-d**, **--dry-run**
> Do not upload files to Codecov.

**--exclude** _DIR_
> Folders to exclude from the coverage file search.

**--plugin** _NAME_
> Plugins to run (xcode, gcov, pycoverage). All run by default.

**--report-type** _coverage|test_results_
> Type of the uploaded files (default: coverage).

**-Z**, **--fail-on-error**
> Exit with non-zero status on upload failure.

**-s**, **--dir** _DIR_
> Search for coverage files in a specific directory (default: current directory).

**-u**, **--enterprise-url**, **--url** _URL_
> Upload host for Codecov Self-Hosted instances (global option, placed before the command).

**--codecov-yml-path** _PATH_
> Path to the codecov.yml file (global option).

**--auto-load-params-from** _PLATFORM_
> CI platform to load parameters from (global option).

**--disable-telem**
> Disable sending telemetry data to Codecov (global option).

**--disable-search**
> Disable automatic coverage file discovery. Use with **--file** to upload only the listed files.

# DESCRIPTION

**codecovcli** is the command-line interface for the Codecov code coverage service. It uploads coverage reports generated by testing frameworks and provides insights through dashboards and pull request comments. It is installed with **pip install codecov-cli**, or as a standalone binary named **codecov** from cli.codecov.io.

The CLI automatically detects CI environments (GitHub Actions, GitLab CI, Jenkins, etc.) and extracts commit, branch, and build information. It searches for coverage files in common formats (lcov, cobertura, jacoco, etc.) and uploads them.

Key commands include **upload-process** (a wrapper that creates a commit, creates a report, and uploads in one step), **upload-coverage**, **do-upload** (upload only), **create-commit**, **create-report**, **empty-upload**, **pr-base-picking**, **process-test-results**, and **send-notifications**. Options not given are loaded from CI environment variables or git where possible.

# CAVEATS

Requires a Codecov account and repository token (or tokenless upload for public repos). Coverage format must be supported (lcov, cobertura, clover, etc.). Private repositories require authentication. Requires Python 3.10 or newer when installed with pip. The older Bash and Node.js uploaders have been deprecated in favor of this CLI.

# HISTORY

Codecov provides code coverage analytics for development teams. In **2022**, Codecov was acquired by **Sentry**. The original Bash uploader was replaced by the Python-based **codecovcli** for improved security and functionality.
