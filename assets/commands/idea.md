# TAGLINE

command-line launcher for IntelliJ IDEA

# TLDR

**Open project**

```idea [project-directory]```

**Open file**

```idea [file.java]```

**Open at line**

```idea --line [42] [file.java]```

**Compare files**

```idea diff [file1] [file2]```

**Merge files**

```idea merge [local] [remote] [base] [output]```

**Wait for IDE** (use as $EDITOR)

```idea --wait [file]```

**Format files** with project code style

```idea format -r -s [code-style.xml] [src/]```

**Install plugins** by ID

```idea installPlugins [com.example.plugin]```

**Run inspections headlessly**

```idea inspect [project_dir] [inspection-profile.xml] [out_dir]```

# SYNOPSIS

**idea** [_options_] [_files_]

**idea** **diff**|**merge**|**format**|**inspect**|**installPlugins** _arguments_

# PARAMETERS

_FILES_
> Files or projects to open.

**--line** _NUM_
> Open the file with the cursor at the given line number.

**--column** _NUM_
> Open at a specific column (combine with **--line**).

**diff** _file1_ _file2_
> Open the diff viewer comparing two files.

**merge** _local_ _remote_ [_base_] _output_
> Open the merge dialog (two- or three-way).

**format** [_options_] _files_
> Apply project code-style formatting to one or more files non-interactively.

**inspect** _project_ _profile_ _output_
> Run code inspection on a project headlessly and write the report to _output_.

**installPlugins** _id_...
> Install plugins by ID from JetBrains Marketplace or a custom repository.

**--wait**
> Block until the opened file is closed (useful as **$EDITOR**).

**nosplash**
> Skip the splash screen at startup.

**dontReopenProjects**
> Show the welcome screen instead of reopening the previous projects.

**disableNonBundledPlugins**
> Launch with only bundled plugins; helpful for troubleshooting.

# DESCRIPTION

**idea** is the command-line launcher for IntelliJ IDEA. It opens files, projects, and invokes IDE features from the terminal.

If an instance is already running, files are opened in it. The **diff** and **merge** commands make it usable as a Git difftool/mergetool, and **--wait** makes it usable as **$EDITOR**. The **format** and **inspect** commands run headlessly, which is useful in CI.

On Linux the launcher is **bin/idea.sh** (or **bin/idea**) in the installation directory, usually symlinked as **idea**; the snap package provides **intellij-idea**, and the JetBrains Toolbox App generates its own **idea** script. On macOS, create a wrapper running **open -na "IntelliJ IDEA.app" --args "$@"**.

# CAVEATS

The **idea** command is not on PATH by default; it must be linked or generated by the Toolbox App. Headless **inspect** runs can be slow and memory-hungry on large projects. Option names like **nosplash** have no leading dashes.

# HISTORY

**IntelliJ IDEA** was first released by **JetBrains** in **2001**. Its open-source core, the IntelliJ Platform, is developed in the intellij-community repository and underlies the other JetBrains IDEs.
