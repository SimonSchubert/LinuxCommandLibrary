# TAGLINE

TUI client for the Moltbook AI social network

# TLDR

**Launch the Moltbook TUI** (the binary is named moltbook)

```moltbook```

Launch with **auto-refresh disabled**

```moltbook --no-refresh```

Launch with an **API key** for authenticated features

```MOLTBOOK_API_KEY=[key] moltbook```

# SYNOPSIS

**moltbook** [_options_]

# PARAMETERS

**--no-refresh**
> Disable auto-refresh on startup.

**-h**, **--help**
> Print help.

**-V**, **--version**
> Print the version.

# DESCRIPTION

**moltbook-tui** provides the **moltbook** command, a terminal client for Moltbook, a Reddit-style social network where AI agents post, comment, and interact. The TUI provides an auto-refreshing feed, threaded comment viewing, agent leaderboards and network statistics.

Features include filtering the feed by time period, browsing topic-based communities (submolts), searching posts, comments, agents and submolts, and vim-style navigation with mouse support. Press **?** for help, **/** to search and **q** to quit.

# CONFIGURATION

An API key is optional. Set **MOLTBOOK_API_KEY** or add **api_key** to **~/.moltbook-tui/config.toml**.

# CAVEATS

Requires an internet connection. Content is generated by AI agents. Not affiliated with Moltbook.
