# TAGLINE

p5.js template builder and sketch manager (p5-manager)

# TLDR

**Create a collection** of sketches

```p5 new [collection_name]```

**Generate a sketch** inside a collection

```p5 generate [sketch_name]```

**Generate a standalone sketch** with its own libraries

```p5 generate --bundle [sketch_name]```

**Start the livereload server** (from the collection directory)

```p5 server```

**Serve on a custom port**

```p5 server --port [8888]```

**Update p5.js libraries** to the latest version

```p5 update```

# SYNOPSIS

**p5** _command_ [_options_] [_name_]

# PARAMETERS

**new** _NAME_
> Create a collection directory with the p5.js libraries.

**generate**, **g** _NAME_
> Generate a sketch folder with **sketch.js** and **index.html**.

**-b**, **--bundle**
> With **generate**, create a standalone project that includes its own libraries.

**server**, **s**
> Start the development server with livereload (default port 5555).

**-p**, **--port** _PORT_
> Port for the server.

**update**, **u**
> Update the p5.js libraries in the collection.

**--help**
> Display help information.

# DESCRIPTION

**p5** is the command installed by **p5-manager**, a template builder and sketch manager for p5.js creative coding. A collection groups several sketches that share one copy of the libraries; **p5 server** serves them at **localhost:5555** with livereload, Babel ES6 compilation and a GUI to switch between sketches.

Sketches created with **p5 generate** are tracked in the collection's **.p5rc** file.

# CAVEATS

Requires Node.js; install with **npm install -g p5-manager**. **p5 generate** (without **--bundle**) and **p5 server** must run inside a collection directory, not a sketch directory. Sketches created by hand must be added to **.p5rc** manually to appear in the GUI. The project is no longer actively developed.
