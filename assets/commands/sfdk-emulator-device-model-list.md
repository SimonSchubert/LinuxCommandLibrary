# TAGLINE

List available Sailfish emulator device models

# TLDR

**List available device models**

```sfdk emulator device-model-list```

# SYNOPSIS

**sfdk emulator device-model-list**

# DESCRIPTION

**sfdk emulator device-model-list** shows the device models a Sailfish OS emulator can emulate. Device models differ in display properties. The active model is controlled by the **device-model** emulator property. Part of the Sailfish SDK command-line tool.
