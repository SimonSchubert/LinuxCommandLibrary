# TAGLINE

Show Sailfish emulator device model details

# TLDR

**Show device model details**

```sfdk emulator device-model-show [model_name]```

**Switch the default emulator to a device model**

```sfdk emulator set device-model=[model_name]```

# SYNOPSIS

**sfdk emulator device-model-show** _model_

# DESCRIPTION

**sfdk emulator device-model-show** displays detailed information about a specific Sailfish OS emulator device model. Part of the Sailfish SDK command-line tool.
