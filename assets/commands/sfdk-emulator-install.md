# TAGLINE

Install Sailfish OS emulator images

# TLDR

**List emulators available for installation**

```sfdk emulator list --available```

**Install an emulator**

```sfdk emulator install [emulator_name]```

# SYNOPSIS

**sfdk emulator install** _name_

# DESCRIPTION

**sfdk emulator install** installs a Sailfish OS emulator from the SDK repositories. The _name_ is the one reported by **sfdk emulator list --available**. Part of the Sailfish SDK command-line tool.
