# TAGLINE

Remove installed Sailfish OS emulators

# TLDR

**List installed emulators**

```sfdk emulator list```

**Remove an emulator**

```sfdk emulator remove [emulator_name]```

# SYNOPSIS

**sfdk emulator remove** _name_

# DESCRIPTION

**sfdk emulator remove** removes an installed Sailfish OS emulator. The _name_ is the one reported by **sfdk emulator list --available**. Part of the Sailfish SDK command-line tool.
