# TAGLINE

Launch the Sailfish SDK Maintenance tool

# TLDR

**Launch the interactive SDK Maintenance tool**

```sfdk maintain```

# SYNOPSIS

**sfdk maintain**

# DESCRIPTION

**sfdk maintain** launches the interactive SDK Maintenance tool. To manage build targets and tooling from the command line, use **sfdk tools** instead. Part of the Sailfish SDK command-line tool.
