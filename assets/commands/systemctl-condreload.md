# TAGLINE

Legacy alias for try-reload-or-restart

# TLDR

This command is an alias of [systemctl try-reload-or-restart](/man/systemctl-try-reload-or-restart).

# DESCRIPTION

**systemctl condreload** is an undocumented compatibility verb kept for ALT Linux. It behaves exactly like `systemctl try-reload-or-restart`. Prefer that name in new scripts.
