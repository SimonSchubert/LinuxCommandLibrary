# TAGLINE

Legacy alias for try-restart

# TLDR

This command is an alias of [systemctl try-restart](/man/systemctl-try-restart).

# DESCRIPTION

**systemctl condrestart** is an undocumented compatibility verb kept for Red Hat style init scripts. It behaves exactly like `systemctl try-restart`. Prefer that name in new scripts.
