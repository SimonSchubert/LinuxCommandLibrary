# TAGLINE

Legacy alias for try-reload-or-restart

# TLDR

This command is an alias of [systemctl try-reload-or-restart](/man/systemctl-try-reload-or-restart).

# DESCRIPTION

**systemctl reload-or-try-restart** is the name this operation had in systemctl 228 and earlier. It is still accepted for compatibility but is no longer documented. Prefer `try-reload-or-restart` in new scripts.
