# TAGLINE

Show available repository candidates for a TeX Live package

# TLDR

**Show package candidates**

```tlmgr candidates [package]```

# SYNOPSIS

**tlmgr candidates** _package_

# PARAMETERS

_package_
> Package name to check.

# DESCRIPTION

**tlmgr candidates** shows the candidate repositories for a package: the install candidate first, with its repository tag and revision, followed by any other repositories providing the package. Part of TeX Live Manager, and mainly useful in multi-repository setups with pinning.
