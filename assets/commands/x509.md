# TAGLINE

X.509 certificate management utility

# TLDR

**Display certificate information**

```openssl x509 -in [certificate.pem] -noout -text```

**Display subject and issuer**

```openssl x509 -in [certificate.pem] -noout -subject -issuer```

**Display certificate dates** (validity period)

```openssl x509 -in [certificate.pem] -noout -dates```

**Display certificate fingerprint**

```openssl x509 -in [certificate.pem] -noout -fingerprint -sha256```

**Convert PEM to DER** format

```openssl x509 -in [cert.pem] -outform DER -out [cert.der]```

**Convert DER to PEM** format

```openssl x509 -in [cert.der] -inform DER -out [cert.pem]```

**Extract public key** from certificate

```openssl x509 -in [certificate.pem] -noout -pubkey```

Show the **Subject Alternative Names**

```openssl x509 -in [certificate.pem] -noout -ext subjectAltName```

**Check whether** a certificate **expires** within a day (exit status 1 if so)

```openssl x509 -in [certificate.pem] -noout -checkend [86400]```

**Inspect a live server's** certificate

```openssl s_client -connect [example.com]:443 -servername [example.com] </dev/null | openssl x509 -noout -subject -dates```

**Self-sign a certificate request** for one year

```openssl x509 -req -in [request.csr] -key [key.pem] -days [365] -out [certificate.pem]```

**Sign a request with a CA**, copying its extensions

```openssl x509 -req -in [request.csr] -CA [ca.pem] -CAkey [ca.key] -CAcreateserial -copy_extensions copy -days [365] -out [certificate.pem]```

# SYNOPSIS

**openssl x509** [**-in** _file_] [**-out** _file_] [**-inform** _DER_|_PEM_] [**-outform** _DER_|_PEM_] [**-noout**] [**-text**] [_options_]

# PARAMETERS

**-in** _file_
> Input certificate file. Reads from stdin if not specified.

**-out** _file_
> Output file. Writes to stdout if not specified.

**-inform** _format_
> Input format: DER or PEM (PEM is tried first by default).

**-outform** _format_
> Output format: DER or PEM (default).

**-noout**
> Prevent output of the encoded certificate.

**-text**
> Print certificate in human-readable text form.

**-subject**
> Print the certificate subject name.

**-issuer**
> Print the certificate issuer name.

**-dates**
> Print the notBefore and notAfter dates.

**-startdate**, **-enddate**
> Print only the notBefore or notAfter date.

**-ext** _names_
> Print the named extensions, comma-separated (e.g. subjectAltName,keyUsage).

**-serial**
> Print the certificate serial number.

**-fingerprint**
> Print certificate fingerprint (use with -sha256, -sha1, etc.).

**-pubkey**
> Output the certificate's public key.

**-req**
> Input is a certificate request, not a certificate.

**-key** _file_
> Private key for signing; without **-CA** this produces a self-signed certificate. **-signkey** is the pre-3.0 name, kept as an alias.

**-new**
> Create a certificate from scratch, without an input certificate or request (requires **-subj**).

**-subj** _name_
> Set the subject name, e.g. "/CN=example.com".

**-days** _n_
> Validity period in days when signing (default: 30).

**-copy_extensions** _none_|_copy_|_copyall_
> Copy extensions from the request with **-req** (default: none, extensions are ignored).

**-extfile** _file_, **-extensions** _section_
> Add extensions from a config file section when signing.

**-CA** _file_
> CA certificate to use for signing.

**-CAkey** _file_
> CA private key for signing.

**-CAcreateserial**
> Create a serial-number file for the CA if one does not already exist.

**-hash**, **-subject_hash**
> Print a hash of the certificate subject (useful for naming trust files).

**-checkend** _sec_
> Exit 0 if certificate will not expire within _sec_ seconds, otherwise exit 1.

**-checkhost** _host_
> Check whether the certificate matches the given host name.

**-modulus**
> Print the public key modulus (compare with **openssl rsa -modulus** to match a key).

**-purpose**
> Print out intended certificate purposes.

# DESCRIPTION

**openssl x509** is a multi-purpose certificate utility that displays certificate information, converts between formats, signs certificate requests, and modifies trust settings.

The command operates on X.509 certificates in PEM or DER format. Common operations include viewing certificate details (subject, issuer, validity, extensions), verifying signatures, converting between formats, and certificate signing.

When signing certificates (acting as a mini-CA), it can self-sign using **-key** or sign using a CA certificate and key with **-CA** and **-CAkey** options. The **-days** option specifies the validity period.

The command is typically invoked as **openssl x509** rather than standalone **x509**.

# CAVEATS

PEM format is the default and more common for certificate exchange. DER format is binary and cannot contain multiple certificates. Only the first certificate of a PEM bundle is read. When converting formats, ensure the correct -inform is specified. Extensions from a CSR are dropped when signing unless **-copy_extensions** or **-extfile** is used, which commonly loses the subjectAltName. Self-signed certificates may not be trusted by browsers without manual exception.

# HISTORY

The **x509** command has been part of **OpenSSL** since its early releases in the late **1990s**. X.509 is an ITU-T standard for public key infrastructure, first published in **1988** and revised multiple times. The OpenSSL implementation provides comprehensive support for certificate manipulation and has become the standard tool for certificate operations on Unix-like systems. OpenSSL 3.0 renamed **-signkey** to **-key** and added **-new**, **-subj** and **-copy_extensions**; since OpenSSL 3.2 generated certificates are X.509 version 3 with key identifier extensions by default.
